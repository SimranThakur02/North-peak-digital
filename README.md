# NorthPeak Digital

A modern, responsive one-page website built for **NorthPeak Digital**, a fictional digital agency. This project was developed as part of a Web Development Internship assignment.

## 📖 About the Project

NorthPeak Digital is a fictional digital agency offering modern web solutions to businesses. The website showcases the agency's services, customer testimonials, pricing plans, and a contact form with client-side validation.

The project focuses on clean UI, semantic HTML, responsive design, accessibility, and performance optimization.

---

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Modern SaaS-inspired UI
- Hero section with Call-to-Action
- Services section with six service cards
- Client testimonials
- Pricing section with three plans
- Contact form with JavaScript validation
- Smooth scrolling navigation
- Accessible semantic HTML
- Optimized for Lighthouse Performance and Accessibility

---

- HTML5
- CSS3

## ♿ Accessibility

The project follows accessibility best practices including:

- Semantic HTML
- Proper heading hierarchy
- Alt text for images
- Labels for form fields
- Keyboard-friendly navigation
- Sufficient color contrast

## ⚡ Performance

Performance optimizations include:

- Optimized image assets
- Lazy loading where appropriate
- Efficient CSS structure
- Minimal JavaScript
- Responsive images
- Lighthouse optimization
